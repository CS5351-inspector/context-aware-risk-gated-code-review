# Inspector Report Explorer

A dependency-free, static interface for the four synthetic Inspector report examples. It displays decisions, analysis coverage, findings, evidence, omissions, resources, source Markdown, and the guarded-publication fallback.

The data is generated by the repository's `npm run examples:report` command from the same production risk, gate, renderer, and guarded publisher used by the report examples. The UI itself makes no model or GitHub requests.

## Run

From this directory, use Node 18 or later:

```sh
npm run dev -- --host 127.0.0.1 --port 7100
```

Open `http://localhost:7100/`. Select a scenario, switch between Overview and Source Markdown, expand coverage details, or copy a report/SHA. Tabs support Left/Right, Home, and End keys.

## Verify and build

```sh
npm test
npm run build
```

The parser tests read the generated `report-data.js`; regenerate it from the repository root if it is missing or stale. `npm run build` writes the standalone static site to `dist/`. The repository's `npm run verify:report` checks that the UI data matches the four committed Markdown reports byte-for-byte.
