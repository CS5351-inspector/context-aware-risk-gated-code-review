**需求原文**

Profiles are isolated per tenant. A lookup returns the profile for the requested tenant/user pair, or null when absent.

**中文对照**

用户资料按租户隔离；返回指定 tenant/user 对应资料，不存在则返回 null。

**AI 对标准答案的判断**

建议保留缺陷 `tenant-cache-key-001`。lookup 按 [tenant,user] 编码键。交换参数后会读取另一个键；对称键共存时能读到另一份资料。

定位：`families/tenant-cache-key/faulty/review.js` 第 2 行。

修复依据：按 cache、tenant、user 的顺序传递参数。

严重性复核：high：明确可返回其他 tenant/user 组合的资料；是否造成真实越权仍取决于实际业务边界。

**是否需要上下文**

cache.js 确认位置参数协议，但旧 diff 的原调用和形参名称已泄露顺序线索；Context 必要性尚待实验。
