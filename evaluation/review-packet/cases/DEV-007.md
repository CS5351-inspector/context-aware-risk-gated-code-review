**需求原文**

For integer indices, readId returns the item id when 0 <= index < items.length and null otherwise. It must not throw for an out-of-range index.

**中文对照**

对于整数下标，0 <= index < items.length 时返回元素 id，其余返回 null；越界不能抛异常。
